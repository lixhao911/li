# 3D 打印上位机 · 使用说明

适用版本：**v1.2.2**　　最后更新：2026-11-09

本文档说明主界面每个设定值到底影响什么参数、生成的表格每一列代表什么，以及完整的操作流程。
PLC 侧配置（DB 变量、TIA 设置、握手 SCL）见 [TIA配置与握手说明.md](TIA配置与握手说明.md)，版本变更见 [CHANGELOG.md](CHANGELOG.md)。

---

## 1. 软件做什么

把 3D 数模（STL / OBJ）变成 G 代码，再把 G 代码转换成**点到点点列**，逐点写入西门子 S7-1212C 的 DB 数据块，驱动 X/Y/Z/E 四个轴。

之所以要“离散化”：S7-1200 的 PTO 步进只支持 `MC_MoveAbsolute`（绝对定位），**没有直线插补**。一条 `G1 X100 Y0` 在 PLC 上只能变成“先到起点、再到终点的跳变”，必须按固定点距拆成一串密集的小目标点，才能近似走出直线。

## 3. 界面设定值 → 具体影响的参数

### 3.1 模型与切片区

| 控件 | 取值范围 / 默认 | 代码中的参数 | 具体影响 |
| --- | --- | --- | --- |
| **层厚 mm** | 0.05 ~ 1.00 / **0.20** | `SlicerSettings.LayerHeight` | 决定切片层数与每层高度 Z。层数 = ⌈模型高度 ÷ 层厚⌉，第 i 层的 Z = 最低点 + 层厚 × i。同时参与挤出量计算（见下），层厚越大每层出丝越多。层厚减小 → 更精细，但点数、发送时间线性增加 |
| **填充间距 mm** | 0.2 ~ 5.0 / **1.0** | `SlicerSettings.InfillSpacing` | 相邻两条填充扫描线的中心距。间距越小填充线越密、路径越长、耗材与点数越多；只影响内部填充，不影响外轮廓走线 |
| **打印点距 mm** | 0.05 ~ 20 / **0.50** | `PointDensifierSettings.MotionPointDistance` | 把每条 G1 按该弧长拆成 ⌈段长 ÷ 点距⌉ 个绝对定位点。**这是最关键的参数**：越小越贴近理论直线，但 PLC 点数、通信次数、总耗时成倍增加；太小会导致电机还没到匀速就减速，出现抖动甚至失步 |
| **空走点距 mm** | 0 ~ 50 / **5.0** | `PointDensifierSettings.TravelPointDistance` | 只作用于 G0 空走段，规则同上。设为 **0** 表示该段不细分，只输出终点一个点（空走不打印，停一下无副作用，但能显著减少 PLC 点数） |

### 3.2 PLC 通信区

| 控件 | 取值范围 / 默认 | 代码中的参数 | 具体影响 |
| --- | --- | --- | --- |
| **IP 地址** | 默认 192.168.0.1 | `PlcService.ConnectAsync` 的 ip | 连接目标 PLC；连不上会在 **5 秒**内报超时并提示检查网线 / 网段 / 允许 PUT-GET |
| **机架** | 0 ~ 10 / **0** | rack | S7-1200 / S7-1200 系列用 **0**（S7-300 才是 0/2） |
| **插槽** | 0 ~ 10 / **1** | slot | S7-1200 用 **1**，填错会连不上 |
| **DB 块号** | 1 ~ 9999 / **1** | `PlcService.DbNumber` | 决定所有读写地址的 DB 前缀（如填 3 则地址为 `DB3.DBD2`、`DB3.DBX0.0`）。**只改块号，块内偏移不变**；必须与 TIA Portal 中建立的 DB 编号一致，且该 DB 要取消“优化的块访问”。发送期间输入框自动锁定，避免中途切换 |
| **每点延时 ms** | 0 ~ 10000 / **0** | `SendAllAsync` 每点末尾 | PLC 已 Ack 之后额外等待的时间，用于人为放慢节奏观察动作；正常联调保持 0，真正的节奏由 PLC 的 Ack 决定 |

### 3.3 固定参数（界面不开放，写死在代码里）

| 参数 | 值 | 位置 | 说明 |
| --- | --- | --- | --- |
| 线宽 | 0.4 mm | `SlicerSettings.LineWidth` | 只用于换算挤出量，不改变路径 |
| 耗材直径 | 1.75 mm | `SlicerSettings.FilamentDiameter` | 用于换算挤出量 |
| 打印速度 | F1500 mm/min | `SlicerSettings.PrintSpeed` | 只在第一条 G1 上写出一次（G 代码模态，后续沿用） |
| 空走速度 | F3000 mm/min | `SlicerSettings.TravelSpeed` | 每条 G0 都带 |
| 连接超时 | 5000 ms | `PlcService.ConnectTimeoutMs` | 超过即判定连接失败 |
| 等 Ack 超时 | 60000 ms | `MainForm.AckTimeoutMs` | 单点等 PLC Ack 的上限，超时中断并报点号 |
| Ack 轮询间隔 | 25 ms | `MainForm.AckPollIntervalMs` | 多久读一次 Ack 位 |
| 外部引擎超时 | 120000 ms | `ExternalSlicer.Slice` | CuraEngine / PrusaSlicer 执行上限 |

## 4. 标准操作流程

1. **① 加载模型**：拖入或点击虚线框选择 `.stl` / `.obj`（STL 支持二进制与 ASCII；OBJ 支持 `v` / `f`，面支持 `a`、`a/b`、`a//b`、`a/b/c` 写法并自动三角化）。加载成功后显示三角面数与外形尺寸。
2. **② 得到 G 代码**（三种任选）：
   - **② 生成 G 代码**：用内置教学级切片器，按当前的层厚与填充间距切片；
   - **导入 G 代码**：装入 Cura / PrusaSlicer 图形界面导出的 `.gcode`（最省事、效果最好）；
   - **外部引擎切片**：直接调用 CuraEngine（`slice -j 配置.json -l 模型 -o 输出`）或 PrusaSlicer（`--slice --load 配置.ini --output 输出 模型`）。
3. **③ 转换为点到点点列**：按打印点距 / 空走点距把长线段拆成密集绝对点。**这一步是给 PLC 发送的前提**；跳过它，PLC 只会得到每条长线的端点，实际走的是“跳点”而不是直线。
4. **④ 连接并发送**：填 IP / 机架 / 插槽 / DB 块号 → 连接 PLC → 可先用「写入选中点（单点）」或「读 PLC 当前坐标」验证读写 → 点「开始发送」按 NewData/Ack 握手逐点下发 → 结束置 Complete。

## 5. 生成表格的每一列

表格数据单元是 `GCodeCommand`，界面显示 6 列（CSV 也是这 6 列）：

| 列名 | 属性 | 含义 | 下发时怎么用 |
| --- | --- | --- | --- |
| **点号** | `LineNo` | 行序号，从 1 开始。切片 / 离散化时按生成顺序编号；CSV 导入时按文件顺序**重新编号** | 写入 `DBW18`（LineNo），只作追溯用 |
| **点到点坐标（G 代码）** | `Code` | 该行 G 代码原文，如 `G1 X10.000 Y20.000 Z0.400 E0.123` | 仅用于显示和 CSV 导出，程序下发时不解析它，而是用后面的结构化列 |
| **X** | `X`（可空） | X 坐标，单位 mm。**空白表示本行没写 X**，G 代码是模态的，沿用上一行的值 | 模态补全后写入 `DBD2`（Real） |
| **Y** | `Y`（可空） | Y 坐标，单位 mm，空白含义同上 | 模态补全后写入 `DBD6` |
| **Z** | `Z`（可空） | Z 坐标（层高），单位 mm，空白含义同上 | 模态补全后写入 `DBD10` |
| **E** | `E`（可空） | **累计挤出量**，单位 mm（不是体积）。表示挤出轴总共推进了多少耗材；G0 空走行为空 | 写入 `DBD14`；G0 行 E 为空时沿用上一个值，等于挤出轴原地不动 |

补充说明：

- **行类型**由 `MotionType` 区分（表格不单独显示，但决定下发行为）：`0 = G0` 快速空走（不出料）、`1 = G1` 打印（出料）。只有这两类行进发送队列，注释、G21、G90、G92 等行被自动跳过。
- **E 的计算**：每走 1 mm，E 增加 `长度 × 线宽 × 层厚 ÷ 耗材截面积`。以默认 0.4 mm 线宽、1.75 mm 耗材为例，截面积 ≈ 2.405 mm²：
  - 层厚 0.2 mm：每 10 mm 路径 E ≈ 0.333 mm；
  - 层厚 0.1 mm：每 10 mm 路径 E ≈ 0.166 mm。
- **离散化后的行**：G1 输出为 `G1 X.. Y.. Z.. E..`（XYZ 与 E 都完整），G0 输出为 `G0 X.. Y.. Z..`（无 E）。离散化会按弧长对坐标与 E 做线性插值，段起点不重复输出。
- **F 值**：程序解析并保存在对象里，但表格与 CSV 不显示（下发 PLC 用不到速度，速度由 PLC 轴参数决定）。

## 6. CSV 表格格式与导入导出

- 表头固定：`LineNo,Code,X,Y,Z,E`；导出为 **UTF-8 带 BOM**，Excel 双击打开中文不乱码。
- 字段含逗号、引号、换行时按 RFC4180 用双引号包裹，内部引号写两遍。
- **导入时只认第 2 列 `Code`**：程序按原文重新解析 X/Y/Z/E，并按文件顺序重新编号；第 1 列和第 3~6 列即使改了也不生效（避免“改了一列数字但原文没改”造成数据不一致）。
- 想手工改坐标，请改 **Code 列文本**，例如把 `G1 X10.000 Y20.000 E0.123` 改成 `G1 X15.000 Y20.000 E0.123`。
- 导入的若是切片器原始 G 代码（长线段），记得再执行一次 **③ 转换为点到点点列**。

## 7. 与 PLC 的地址对应

DB 块号取界面值 `n`，块内偏移固定：

| 变量 | 地址 | 方向 | 含义 |
| --- | --- | --- | --- |
| NewData | `DBn.DBX0.0` | PC → PLC | 新点已就绪 |
| Ack | `DBn.DBX0.1` | PLC → PC | 该点已取走 / 已入队 |
| Complete | `DBn.DBX0.2` | PC → PLC | 全部点发送完毕 |
| X / Y / Z / E | `DBn.DBD2 / 6 / 10 / 14` | PC → PLC | Real，单位 mm |
| LineNo | `DBn.DBW18` | PC → PLC | Int，点号 |
| MotionType | `DBn.DBW20` | PC → PLC | Int，0=G0，1=G1 |

握手顺序：写数据 → `NewData=1` → 等 `Ack=1` → `NewData=0` → 等 `Ack=0` → 下一点；全部完成置 `Complete=1`。

## 8. 参数怎么调（经验值）

- **点数估算**：总点数 ≈ Σ 每段 ⌈段长 ÷ 点距⌉。参考：20 mm 立方体在层厚 0.2 mm、填充 1.0 mm、打印点距 0.5 mm 下，离散后约 **9.8 万个点**，PLC 侧要跑很久，实际生产建议先用大点距验证流程。
- **打印点距**：从 0.5 mm 起步。太小 → 电机频繁加减速、抖动失步；太大 → 斜线变明显折线。
- **空走点距**：从 5 mm 起步；只关心少发点数可设 0（每段只发终点）。
- **层厚 / 填充间距**：先用 0.2 / 1.0 跑通，再按精度与耗时权衡调整。
- **判断标准**：点距要明显大于“轴从静止加速到匀速所走的距离”，否则每点都走不完加速段。

## 9. 注意事项

1. PLC 侧该 DB 必须**取消“优化的块访问”**，CPU 必须勾选**允许 PUT/GET**，否则能连上却读写失败。
2. 第一次联调建议先在 PLC 里只用最小握手程序（收到 NewData 立刻回 Ack）验证通信，再接四轴 `MC_MoveAbsolute`。
3. 「写入选中点（单点）」只写数据、不置 NewData，PLC 不会动作；且该功能对“未写出某轴”的行按 0 补齐，**建议只对离散化后的完整行使用**。
4. 发送过程中点「停止」只是取消上位机循环，**NewData 可能仍保持为 1**；再次发送前程序会先将其清零，PLC 侧也建议做上电/复位清零。
5. 逐点发送采用“一个点一次握手”，当前实现为逐点写 6 次寄存器，点数很多时速度受限；如需提速，可改为一次性写整块 DB 或用 2~5 点缓冲队列（见 TIA 文档）。
